## D-001: Editorial Minimalism вместо Ultra WOW
- **Решение:** Убрать 40+ анимаций → CSS transitions + FadeIn
- **Почему:** SSR ошибки, пустые зоны, сломанный мобильный
- **Альтернативы:** Починить существующие — слишком много inter-dependencies
- **Пересмотреть:** Если нужен wow для инвесторов — только CSS scroll-driven
- **Дата:** 2026-07-02

## D-002: Один файл < 250 строк
- **Решение:** Жёсткий лимит 250 строк
- **Почему:** AI ломает файлы > 400 строк (доказано BUG-009: 1332 строки)
- **Альтернативы:** 400 — слишком близко к порогу ошибок
- **Пересмотреть:** При автоматической проверке в CI
- **Дата:** 2026-07-02

## D-003: Warm Biophilic Luxury
- **Решение:** #F5F1EA + #D4A843 вместо #FAFAF7 + #B8860B
- **Почему:** Тёплые тона бьют холодные для food (Coloracci 2026)
- **Альтернативы:** Dark premium — не конвертирует для кейтеринга
- **Пересмотреть:** При A/B тесте или ребрендинге
- **Дата:** 2026-07-03

## D-004: SubpageLayout — единый шаблон
- **Решение:** SubpageLayout.tsx для всех подстраниц
- **Почему:** 16 страниц × дублированный код = 16 мест для багов
- **Альтернативы:** Layout в app/ — ограничивает кастомизацию hero
- **Пересмотреть:** Если подстраницам нужна разная структура
- **Дата:** 2026-07-03

## D-005: WhatsApp как основной CTA
- **Решение:** CTA → WhatsApp с предзаполненным текстом
- **Почему:** Формы конвертируют хуже, ломались
- **Альтернативы:** Формы + WhatsApp параллельно — для /contacts
- **Пересмотреть:** Если подключим CRM
- **Дата:** 2026-07-03

## D-006: Agent OS вместо монолитного MEMORY.md
- **Решение:** MEMORY/ директория с INDEX вместо одного файла
- **Почему:** MEMORY.md вырос до 600+ строк с противоречиями
- **Альтернативы:** Внешняя БД — overengineering
- **Пересмотреть:** При 50+ страницах или 3+ разработчиках
- **Дата:** 2026-07-03

## D-007: "use client" вместо ssr: false
- **Решение:** `"use client"` директива для клиентских компонентов
- **Почему:** Next.js 16: ssr: false не работает в Server Components
- **Альтернативы:** Нет в Next.js 16
- **Пересмотреть:** При обновлении Next.js
- **Дата:** 2026-07-02

## D-008: Memory Tiering (CORE/RECALL/ARCHIVAL)
- **Решение:** 3 уровня памяти по Letta/MemGPT
- **Почему:** Без tiers агент загружал всё или ничего
- **Альтернативы:** 2 уровня — недостаточно; 5 — overengineering
- **Пересмотреть:** Если CORE.md превысит 500 токенов
- **Дата:** 2026-07-04

## D-009: CORE.md как SSOT
- **Решение:** Контакты/дизайн/стек только в CORE.md
- **Почему:** arXiv:2606.15828 — дублирование #2 smell
- **Альтернативы:** Распределённый — привело к противоречиям
- **Пересмотреть:** Если CORE.md превысит 80 строк
- **Дата:** 2026-07-04

## D-010: Routing Table для детерминированного boot
- **Решение:** Таблица "тип задачи → какие файлы загрузить"
- **Почему:** Без routing boot был недетерминирован
- **Альтернативы:** Авто-определение через LLM — ненадёжно
- **Пересмотреть:** Если типов задач станет > 10
- **Дата:** 2026-07-04

## D-011: EXECUTION.md — движок достижения результатов
- **Решение:** Отдельный файл с пошаговыми протоколами
- **Почему:** Память без execution = хранение, не достижение
- **Альтернативы:** Встроить в AGENT_BOOT — слишком длинный
- **Пересмотреть:** Если протоколов станет > 10
- **Дата:** 2026-07-04

## D-012: patterns.md — готовые решения кода
- **Решение:** Шаблоны кода в MEMORY/QUALITY/patterns.md
- **Почему:** Без паттернов агент повторяет ошибочные подходы
- **Альтернативы:** В LEARNINGS — смешивает разные типы знаний
- **Пересмотреть:** Если файл превысит 250 строк
- **Дата:** 2026-07-04
