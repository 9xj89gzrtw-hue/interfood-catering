## Ключевые принципы (из Zylos.ai)

### 1. Маленький загрузчик, распределённая память
- AGENT_BOOT.md < 150 строк — только boot protocol + указатели
- MEMORY/ — специализированные файлы по типу знаний
- INDEX.md — каталог для быстрого поиска

### 2. Правила сжатия
- Не хранить 20 страниц исследования — хранить: Источник → Главный вывод → Дата → Когда перепроверить → Ссылка
- Объединять дублирующиеся знания
- Архивировать устаревшее (не удалять)

### 3. Anti-patterns из arXiv
- ❌ Context bloat — бесконечное накопление контекста в одном файле
- ❌ Дублирование — одна и та же информация в нескольких местах
- ❌ Устаревшие инструкции — не обновлённые после смены подхода
- ❌ Ambiguous directives — "be careful" вместо конкретных правил

### 4. Decision Memory
- Хранить не "мы читали статью", а: Решение → Почему → Альтернативы → Когда пересмотреть
- Это позволяет новому агенту понять контекст без чтения оригинальной статьи

### 5. Self Improvement Loop
- После каждой задачи: Что узнал? → Что стало правилом? → Что НИКОГДА не делать? → Что архивировать?
- Это превращает каждую сессию в улучшение системы, а не просто выполнение задачи
