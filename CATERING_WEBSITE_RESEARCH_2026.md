## 1. CLIENT DECISION JOURNEY

### 1.1 How SPb Clients Search for Catering

**First search queries (by frequency):**
- "Кейтеринг Санкт-Петербург" / "Кейтеринг СПб" (generic awareness search)
- "Кейтеринг на свадьбу СПб" / "Фуршет с доставкой СПб" (format-specific)
- "Кейтеринг корпоратив Санкт-Петербург" / "Кофе-брейк офис СПб" (event-specific)
- "Заказать банкет СПб недорого" / "Фуршетное меню с ценами" (price-intent)
- "Кейтеринг отзывы СПб" / "Лучший кейтеринг Петербург" (trust-building)

**Search engine behavior:**
- **Yandex dominates** (60-65% of Russian search), Google has ~35%
- 53% of buyers start with a generic search, NOT naming a specific brand
- Local search is critical: clients add "СПб", "Санкт-Петербург", "Петербург" to queries
- Yandex Maps / 2GIS integration is essential for local discovery
- Clients search by **format first** (фуршет, банкет, кофе-брейк), then by price

### 1.2 The Typical Decision Journey (5 Stages)

```
Stage 1: AWARENESS (Search / Social / Word-of-mouth)
   ↓  "I need food for an event"
Stage 2: EXPLORATION (3-7 sites, aggregators like catery.ru, profi.ru)
   ↓  Compare formats, menus, photos, rough prices
Stage 3: EVALUATION (2-3 shortlisted companies)
   ↓  Read reviews, check gallery, try calculator, message on Telegram/WhatsApp
Stage 4: CONVERSION (Request quote / Call / Send message)
   ↓  Fill form, send TG message, or call
Stage 5: LOYALTY (Repeat order / Referral)
   ↓  Email follow-up, seasonal menu updates, referral program
```

**Key insight:** The journey is **not instant**. Catering is a high-consideration purchase. Clients compare 3-7 companies over days or weeks. The website must serve every stage of this journey.

### 1.3 What Information Clients Need to Decide

| Priority | Information Needed | Where They Look |
|----------|-------------------|-----------------|
| 1 | **Price range per person** | Calculator page, format pages |
| 2 | **Real photos of events** | Gallery, format-specific pages |
| 3 | **Menu options with photos** | Menu page with categories |
| 4 | **Reviews from similar events** | Reviews page, Yandex/2GIS |
| 5 | **Format explanation** (what's a фуршет vs банкет?) | Format landing pages |
| 6 | **Minimum order amount** | FAQ, format pages |
| 7 | **What's included** (staff, equipment, delivery) | Service pages |
| 8 | **Venue options** | Venue/partner page |
| 9 | **Company story/team** | About page |
| 10 | **Response speed** | Implied by WhatsApp/Telegram presence |

### 1.4 Client Concerns & Fears

1. **"Will the food be enough?"** — Portion sizes are unclear
2. **"Will it arrive on time?"** — Reliability anxiety
3. **"Hidden costs"** — Price per person vs total cost unclear
4. **"Food quality vs photos"** — Is what I see what I'll get?
5. **"What if guests have dietary needs?"** — Vegan, halal, gluten-free options
6. **"Who serves the food?"** — Is staff included? Professional waiters?
7. **"What about dishes/equipment?"** — Extra rental fees?
8. **"Can I customize the menu?"** — Flexibility concern
9. **"What if something goes wrong?"** — No clear guarantee or refund policy
10. **"How far in advance to order?"** — Lead time uncertainty

### 2.2 Why Each Format Needs Its Own Page (SEO + Conversion)

**Critical SEO insight:** Each format page targets a distinct search cluster:
- `/furshet` → "фуршет СПб", "фуршетное меню", "фуршет с доставкой"
- `/banket` → "банкет СПб", "банкетное меню", "заказать банкет"
- `/svadba` → "кейтеринг на свадьбу", "свадебный банкет СПб"
- `/coffee-break` → "кофе-брейк офис", "кейтеринг конференций"

Each page must include:
- Format description (what it is, when to choose it)
- Starting price per person (e.g., "от 1 790 ₽/чел")
- Sample menu with photos
- Gallery from real events in this format
- Client reviews for this specific format
- Quick-quote form pre-filled with the format type
- CTA: "Заказать [фуршет/банкет/...]"

### 2.3 Calculator Page — The #1 Conversion Tool

The calculator is mentioned by Yandex experts and top-performing catering sites as a **must-have commercial factor**. It should:
- Let users select: format, number of guests, date, budget range
- Show instant estimate ("Ваш ориентировочный заказ: от X ₽")
- Offer to send a detailed quote via Telegram/WhatsApp/email
- Include a 10% discount for filling it out (common conversion tactic in Russian catering)

### 2.4 Venue / Partner Page

**Yes, this is important.** Many SPb clients don't have a venue and need the caterer to provide or recommend one. The page should:
- List partner venues with photos, capacity, and price ranges
- Show venue + catering packages (bundle = higher conversion)
- Include a map of SPb and Leningrad Oblast locations
- Feature "popular combinations" (e.g., "Лофт + фуршет на 50 человек = от 3 500 ₽/чел")

### 2.5 Corporate Clients Page

**Essential for B2B revenue.** Corporate catering has different needs:
- Recurring orders (weekly lunches, regular conferences)
- Contract pricing and volume discounts
- Compliance/invoice requirements (закрытие документов, ЭДО)
- Dedicated account manager promise
- Case studies with company logos (with permission)
- Downloadable presentation/PDF for procurement departments

## 3. CONVERSION OPTIMIZATION

### 3.1 CTA Button Placement & Strategy

| Location | CTA Text | Format |
|----------|----------|--------|
| **Header (sticky)** | Phone number + "Заказать звонок" | Click-to-call button |
| **Hero section** | "Рассчитать стоимость" / "Получить меню" | Primary button, large |
| **After price info** | "Заказать [фуршет/банкет]" | Context-specific |
| **Floating (mobile)** | WhatsApp + Telegram icons | Bottom-right corner |
| **Gallery section** | "Хотите так же? Закажите!" | Emotional trigger |
| **Reviews section** | "Станьте нашим довольным клиентом" | Social proof driven |
| **Footer** | Full contact form + messengers | Comprehensive |
| **Exit-intent popup** | "Получите скидку 10% на первый заказ" | Last chance offer |

**CTA color:** Use a warm, appetite-stimulating color (orange, warm red) — research shows these convert 20-30% better for food businesses.

### 3.2 Form Fields That Convert Best

**The golden rule:** Fewer fields = higher conversion. Average form conversion is 1.7%, but top performers hit 11%+.

**Optimal short form (hero/float):**
1. Имя (Name) — optional, auto-fill
2. Телефон (Phone) — **required**, masked input +7 (___) ___-__-__
3. Тип мероприятия (Event type) — dropdown: Фуршет / Банкет / Свадьба / Кофе-брейк / Корпоратив / Другое
4. Количество гостей (Guest count) — number input or slider
5. Дата (Date) — date picker

**Extended form (calculator page):**
Add: Budget range, Venue (yes/no), Special requirements (textarea), Preferred contact method (Phone/WhatsApp/Telegram)

**Critical:** Phone field is the #1 conversion killer. Make it the only required field alongside event type. All else is optional or can be asked later by the manager.

### 3.3 Trust Signals — Ranked by Impact

| Rank | Trust Signal | Impact | Implementation |
|------|-------------|--------|----------------|
| 1 | **Real event photos** (not stock) | ⭐⭐⭐⭐⭐ | Gallery with event descriptions |
| 2 | **Named client reviews** with event type & guest count | ⭐⭐⭐⭐⭐ | "Корпоратив на 150 чел, декабрь 2025" |
| 3 | **Yandex/2GIS rating badge** | ⭐⭐⭐⭐⭐ | Live widget showing 4.8+ rating |
| 4 | **Years in business** ("10 лет на рынке") | ⭐⭐⭐⭐ | Counter or badge in hero |
| 5 | **Number of events served** ("2 000+ мероприятий") | ⭐⭐⭐⭐ | Social proof counter |
| 6 | **Corporate client logos** | ⭐⭐⭐⭐ | Logo wall on corporate page |
| 7 | **Video testimonials** | ⭐⭐⭐⭐ | 30-60 second clips |
| 8 | **Certifications / HACCP / Sanitary compliance** | ⭐⭐⭐ | Footer or about page |
| 9 | **Media mentions / awards** | ⭐⭐⭐ | Press section |
| 10 | **Guarantee / Refund policy** | ⭐⭐⭐ | FAQ or dedicated page |

### 3.4 Phone Number Visibility

- **Must be in the sticky header** — the first thing visitors see
- Use click-to-call: `<a href="tel:+7812XXXXXXX">+7 (812) XXX-XX-XX</a>`
- Show hours of operation next to the number
- For after-hours: show "Оставьте заявку — перезвоним утром"
- **Color contrast:** Phone number must stand out against header background
- Mobile: tappable phone icon + number, minimum 44px touch target

### 3.5 WhatsApp / Telegram Integration

**This is non-negotiable for Russia in 2026.**

- **WhatsApp:** Direct link `https://wa.me/7812XXXXXXX?text=Здравствуйте! Хочу заказать кейтеринг`
- **Telegram:** Direct link `https://t.me/yourusername` or inline bot button
- Position: Floating buttons (bottom-right), sticky header, and every CTA section
- Pre-fill messages: "Здравствуйте! Интересует кейтеринг на [формат] на [N] человек"
- Consider a **Telegram Mini App** for menu browsing + ordering inside Telegram
- WhatsApp Business API for automated quick replies

## 4. MOBILE BEHAVIOR IN RUSSIA

### 4.1 Mobile Market Share in Russia (2025-2026)

| Platform | Market Share |
|----------|-------------|
| **Android** | 58.6% |
| **iOS** | 41.4% |
| **Samsung/Tizen** | <0.1% |

**Mobile internet penetration:** 92.2% of Russia's 133M internet users access the web via mobile. Over 64% of catering website traffic will come from mobile devices.

### 4.2 Telegram WebView Behavior

**Critical technical considerations:**

1. **Telegram opens links in its in-app browser (WebView)**
   - On iOS: Uses a WebKit-based browser similar to Safari, but with **limitations**
   - No "Add to Home Screen" option from Telegram WebView
   - Limited push notification support
   - No Face ID / Touch ID for payment
   - Session cookies may behave differently

2. **iOS Safari limitations that affect Telegram WebView:**
   - Durov publicly criticized Apple for restricting Safari WebKit features
   - No WebRTC support in WebView context
   - No background audio/video playback
   - Autoplay restrictions on video content
   - Limited PWA capabilities (no push notifications in WebView)

3. **Design for Telegram WebView:**
   - **No hover states** — everything must work with tap
   - Avoid complex animations that lag in WebView
   - Ensure forms work without autofill (which is limited in WebView)
   - Test with `window.Telegram.WebApp` API for native-looking integration
   - Use `Telegram.WebApp.MainButton` for primary CTA inside Mini App
   - Consider building a **Telegram Mini App** (separate from the website) for the best in-app experience

4. **Telegram Mini App opportunity:**
   - 96M Russian Telegram users (January 2025)
   - Zero install friction — opens inside Telegram
   - Can access user's Telegram ID, name, language
   - Payment integration via Telegram Payments
   - Best for: menu browsing, quick quote requests, order tracking

### 4.3 Safari on iPhone (41% of Russian mobile)

- Test extensively on Safari — it has the most WebView restrictions
- Use `-webkit-` prefixes for CSS features
- Avoid `position: fixed` bugs on iOS Safari (use `position: sticky`)
- Handle safe areas for notch/Dynamic Island devices
- Video must have `playsinline` attribute to autoplay
- Touch targets minimum 44x44px (Apple HIG)
- Don't rely on `:hover` — use `@media (hover: hover)` progressive enhancement

### 4.4 Most Popular Messaging Apps for Business Inquiries in Russia

| App | Monthly Users in Russia | Business Usage |
|-----|------------------------|----------------|
| **Telegram** | ~96M (Jan 2025) | #1 for business inquiries, bots, Mini Apps |
| **WhatsApp** | ~89M (Jan 2025) | #2 for direct client communication |
| **Max (state app)** | ~74M | Growing but low business adoption |
| **VK Messenger** | ~40M+ | Integrated with VK ecosystem |

**Recommendation for SPb catering:**
1. **Telegram** — Primary business channel (bot, Mini App, direct messages)
2. **WhatsApp** — Secondary, for clients who prefer it
3. **VK** — Tertiary, especially for wedding segment (VK is huge for wedding planning)
4. **Phone call** — Still essential for corporate/older demographics

**Note:** Russia is throttling both WhatsApp and Telegram voice calls (2025-2026). Text messaging works fine. Plan for text-first communication.

## 5. CONTENT THAT SELLS CATERING

### 5.1 Photos That Convert

**The #1 investment for catering marketing is professional food photography.** This was emphasized across every source — from Yandex's official guide to FoodShot's 2026 marketing playbook.

**Photo types ranked by conversion impact:**

1. **Real event setups** — Full buffet tables, decorated venues, guests interacting with food
   - Shows scale and professionalism
   - Must show real events, NOT stock photos
   - Include venue name and guest count in caption

2. **Close-up food shots** — Individual dishes, canapé boards, dessert stations
   - Natural lighting, no harsh flash
   - Show texture and freshness
   - Photos with dishes on slate boards, wooden planks convert well

3. **Before/After transformations** — Empty venue → fully set up
   - Extremely effective on social media and gallery
   - Shows the "magic" of the service

4. **Staff in action** — Chefs cooking, waiters serving, bartenders mixing
   - Humanizes the brand
   - Shows professionalism and service quality

5. **Client reaction shots** — People smiling, enjoying food
   - Emotional connection
   - Best when candid, not posed

**Technical photo requirements:**
- WebP format with JPEG fallback
- Hero images: 1920x1080 minimum
- Gallery thumbnails: 600x400
- Menu item photos: 800x600
- Lazy load all below-fold images
- Compress to <100KB per image

### 5.2 Menu Presentation Format

**The menu page must have:**
- **Category filter tabs:** Фуршет / Банкет / Кофе-брейк / Напитки / Десерты / Вегетарианское
- **Photo + name + portion size** for each dish (NOT just a text list)
- **Price per unit or per person** where applicable
- **"Popular" or "Рекомендуем" badges** on best-sellers
- **Dietary labels:** 🌱 Вегетарианское, 🥜 Без глютена, 🥛 Без лактозы
- **PDF download option** — many corporate clients need to share menus internally
- **Interactive calculator** — select dishes and see running total

**Research stat:** Restaurants that switched from text-only menus to photo menus saw a **up to 65% increase in conversion**. For catering, where clients can't taste before ordering, visual trust is even more critical.

### 5.3 Social Proof That Works

**Most convincing → Least convincing:**

1. **Video testimonials** (30-60 sec) — Client describes their event, shows the food
   - Increases conversion by 34%
   - Must include event type, guest count, date

2. **Detailed written reviews with specifics** — "Заказывали фуршет на корпоратив 120 человек. Всё вовремя, официанты отличные."
   - Specificity = credibility
   - Include: event type, guest count, what they liked

3. **Yandex/2GIS review widgets** — Live, verifiable, third-party
   - Russian clients trust Yandex reviews highly
   - Embed the widget, don't just claim the rating

4. **Case studies** — "Компания X: Корпоратив на 200 человек, лофт на Петроградке"
   - Especially effective for B2B
   - Include photos, budget range, client quote

5. **Social media embeds** — Instagram/VK posts from real events
   - Shows ongoing activity
   - Client-generated content is gold

6. **Number counters** — "2 000+ мероприятий", "500+ корпоративных клиентов"
   - Simple but effective in hero section

**What NOT to do:** Fake reviews with no specifics. "Отличный кейтеринг, всем советую!" is useless.

### 5.4 Video Content Importance

**Video is the fastest-growing content format for catering in 2026.**

**Must-have videos:**
1. **Hero background video** (15-20 sec, muted, loop) — Shows food preparation, event setup, guests enjoying
2. **Format explainer videos** (30-60 sec each) — "Что такое фуршет?", "Как проходит банкет?"
3. **Behind-the-scenes** (15-30 sec Reels/Shorts) — Chef cooking, team loading van, setting up venue
4. **Client testimonials** (30-60 sec) — See above
5. **Virtual venue tours** — 360° or walkthrough of partner venues

**Video performance stats:**
- Video testimonials increase conversions by 34%
- ~60% of guests tried a restaurant after seeing its food on social media
- Reels/Shorts get 2-3x more reach than static posts for food content

**Technical video requirements:**
- Autoplay muted in hero (15-20 sec max, compressed)
- All other videos: click-to-play with poster frame
- WebM + MP4 formats
- Keep under 5MB for hero video
- Subtitles on all videos (many watch without sound)
- Lazy load video players

## 6. ADDITIONAL RECOMMENDATIONS FOR SPB 2026

### 6.1 Seasonality Strategy

| Season | Peak Demand | Website Emphasis |
|--------|------------|-----------------|
| Dec-Jan | New Year corporate events | Prominent "Новогодний корпоратив" banner, seasonal menus |
| May-Sep | Wedding season | Wedding page hero, venue packages |
| Sep-Oct | Corporate conferences | Coffee-break/corporate page, B2B push |
| Mar-Apr | Graduation planning starts | "Выпускной" section, school/university packages |

### 6.2 2025-2026 Catering Trends (from Russian industry sources)

1. **Personalization** — Clients expect custom menus, not standard packages
2. **Local/Regional ingredients** — Russian products emphasis (снижение затрат + патриотичный маркетинг)
3. **Sustainable/eco-friendly** — "Устойчивое питание", less waste
4. **Vegan/vegetarian options** — Growing demand, must be visible on menu
5. **Mocktails & non-alcoholic bars** — Trend at events in 2025
6. **Open cooking stations** — Live cooking as entertainment
7. **Delivery in elegant boxes** — Post-COVID format still popular (Солнце Кейтеринг model)
8. **Interactive food stations** — DIY taco bars, make-your-own dessert

### 6.3 Technical Performance Requirements

- **Lighthouse score:** >90 on mobile
- **LCP (Largest Contentful Paint):** <2.5s
- **CLS (Cumulative Layout Shift):** <0.1
- **FID (First Input Delay):** <100ms
- **Image format:** WebP with JPEG fallback
- **Hosting:** Server in Russia or nearby (St. Petersburg / Moscow) for <50ms latency
- **CDN:** Consider Yandex Cloud or Selectel for Russian audience
- **SSL:** Mandatory (Let's Encrypt minimum)
- **Analytics:** Yandex Metrika + Google Analytics (both, because Yandex is dominant in Russia)

### 6.4 Legal/Compliance for Russian Market

- Privacy policy (Политика конфиденциальности) — required by Russian law
- Cookie consent banner — required
- User agreement (Пользовательское соглашение)
- Display: INN, OGRN, legal address in footer
- GDPR not applicable, but Russian Federal Law 152-ФЗ on Personal Data is
- All personal data must be stored on servers physically located in Russia
