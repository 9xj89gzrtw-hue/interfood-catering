6 принципов дизайна 2026

Каждый принцип — это конкретная метрика и результат. Не абстракции, а цифры, которые вы увидите в Яндекс.Метрике через месяц после запуска.

01 LCP < 2.5s

Еда на первом экране

Полноэкранное hero-изображение с настоящей едой, не с абстракцией. Гость должен за 1 секунду понять: «это про еду, это про праздник».

Почему: 75% потребителей оформляют заказы с мобильного (Mobile First 2026). Первое впечатление за 0.05 секунды по исследованию Google. Большое аппетитное фото еды сразу снимает вопрос категории бизнеса.
Делать: Использовать профессиональную food-фотографию от шефа; естественный свет, глубокие тарелки, пара на заднем плане, рука официанта в кадре
Не делать: Стоковые фото с шампурами; абстрактные градиенты; видео с автоигрой и звуком; splash-экраны
02 +18–32% заявок

Прозрачность цены

На сайте должен быть калькулятор «гости × формат = ориентировочная стоимость» и понятная вилка «от X ₽/гость». Без этого клиент уходит к конкурентам.

Почему: Catering by Michaels публикует цены на сайте и получает на 32% больше квалифицированных заявок. Премиум-сегмент в РФ часто скрывает цены — это создаёт раздражение у среднего сегмента.
Делать: Калькулятор с 3-4 параметрами (дата, гости, формат, дополнительные опции); вилка «от X ₽/гость» по каждому формату; кнопка «рассчитать точно»
Не делать: PDF с прайсом; надпись «цена по запросу» без вилки; скрытые обязательные платежи
03 +22% конверсия

Липкий CTA на мобильном

На мобильном внизу экрана всегда прикреплена кнопка «Рассчитать стоимость» или «Связаться в Telegram». На десктопе — sticky-кнопка справа.

Почему: Chowly и HubSpot 2026: sticky CTA на мобильном увеличивает конверсию на 18–22%. Гость не должен скроллить вверх, чтобы оставить заявку.
Делать: Плавающая кнопка снизу 56px высотой, контрастная, с иконкой Telegram/телефона; безопасные отступы для iPhone (safe-area-inset-bottom)
Не делать: Кнопка только в шапке; мелкие CTA <44px; CTA того же цвета, что фон
04 +7–400% к доверию

Доверие в каждом блоке

Каждый экран сопровождается социальным доказательством: отзывы, логотипы клиентов, годы на рынке, количество событий, сертификаты.

Почему: Baymard Institute: доверие — главный фактор покупки онлайн. Trust badges поднимают конверсию от +7% до +400% в зависимости от ниши. Для кейтеринга критично: гость платит вперёд за невидимый результат.
Делать: Реальные отзывы с фото клиентов; логотипы корпоративных заказчиков; счётчик «500+ событий»; ссылки на 2ГИС/Яндекс.Карты с реальными оценками
Не делать: Выдуманные отзывы без имен/дат; логотипы «партнёров» без договоров; счётчики с круглыми числами без расшифровки
05 Bounce rate −27%

Решение на одном экране

На первом экране гость видит: что это (еду), для кого (свадьбы/корпоративы/дни рождения), сколько примерно стоит, и куда нажать. Без скролла.

Почему: NN/g 2026: 70% внимания пользователей остаётся above the fold. Hero с одной чёткой ценностью и одним CTA снижает bounce rate на 27% (Marketingexperiments 2026).
Делать: Заголовок H1 = что + для кого + город; подзаголовок с уникальным обещанием; одна первичная кнопка; миниатюра калькулятора «от X ₽/гость»
Не делать: Карусель из 5 слайдов в hero; 3 разные кнопки; абстрактные заголовки «Искусство вкуса» без сути
06 LCP < 2.5s, INP < 200ms

Производительность = продажи

Сайт грузится за 2 секунды на 4G. Каждая лишняя секунда −7% конверсий. Core Web Vitals 2026: LCP < 2.5s, INP < 200ms, CLS < 0.1.

Почему: Google 2026: сайты с плохими CWV теряют до 27% органики. Akamai: задержка 100ms = −7% конверсий. На мобильном 4G каждые 500ms задержки = −12% дочитываемости страниц.
Делать: Картинки в WebP/AVIF с width/height; lazy-loading с native API; шрифты подгружаются через font-display: swap; CSS критический инлайнится
Не делать: PNG-фотографии по 2MB; видео-фон без fallback; Google Fonts без preconnect; слайдеры на тяжёлых библиотеках

Editorial asymmetric hero

Бенто-сетка с одним крупным фото и 3-4 мини-блоками

  • Хорошо работает на десктопе (8-col grid) и мобильном (2-col stack)
  • Снимает проблему «что показать в hero» — можно показать всё сразу

Что улучшить

  • На мобильном bento должен превращаться в простой stack — иначе перегруз
  • Не использовать 4 разных шрифта в 4 блоках — шрифт один, акценты цветом

Ежемесячный контент-апдейт

Блог + кейсы + сезонное меню

Сайт — не «сделал и забыл». Раз в месяц: новый кейс (фото + описание), новый пост в блоге (тренды, советы), обновление сезонного меню. Поисковики любят свежий контент — рост позиций.

Что усиливает продажи

  • Блог: «Как выбрать кейтеринг для свадьбы 100 гостей» — SEO-трафик
  • Кейсы: 1 в месяц = 12 в год = портфолио растёт
  • Сезонное меню: март = весеннее, сентябрь = осеннее — повод написать клиенту
  • Email-рассылка: 1 раз в месяц с новостями и предложением

Что улучшить

  • Не копировать контент с других сайтов — Google penalizes за дубли
  • Не оставлять блог без новых постов >2 месяцев — теряется SEO-эффект

In-app browser совместимость

Telegram, iMessage, WhatsApp, VK

В РФ 60% переходов с рекламы открываются в in-app браузерах Telegram/VK/WhatsApp. Эти браузеры урезаны: нет Google Fonts, нет IntersectionObserver, backdrop-filter не работает. Сайт должен быть self-contained.

Что усиливает продажи

  • System font stack: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
  • Все CSS inline в — не блокируется
  • Все JS inline в конце — с defer
  • Нет backdrop-filter — только solid backgrounds с opacity
  • Нет position: sticky — только fixed или static
  • SVG inline — не external файлы

Что улучшить

  • Не использовать Google Fonts — может не загрузиться в in-app
  • Не использовать WebP/AVIF без JPEG fallback — Safari 13 и ниже не поддерживают

Чек-лист запуска

Что обязательно должно быть на сайте

Сжатый списокmust-have для запуска сайта кейтеринга в России в 2026 году. Проверьте себя перед релизом.

Юридическое (152-ФЗ)

  • 3 отдельных согласия: на ПДн (обязательное), на cookies (обязательное), на промо (опциональное) — с 01.09.2025 раздельно
  • Политика обработки ПДн в футере, ссылка с каждой формы
  • Возможность отозвать согласие в 1 клик (ссылка в каждом письме)
  • Не использовать Google Analytics — запрещён в РФ с 01.07.2025; только Яндекс.Метрика
  • Хостинг в РФ (Selectel, Timeweb) — данные россиян в России

Производительность (Core Web Vitals 2026)

  • LCP < 2.5s — Largest Contentful Paint,hero-изображение должно загрузиться быстро
  • INP < 200ms — Interaction to Next Paint, сайт должен откликаться мгновенно
  • CLS < 0.1 — Cumulative Layout Shift, без «прыгающих» элементов
  • Картинки в WebP/AVIF, у всех width/height
  • Critical CSS инлайнится, остальное через defer
  • Шрифты с font-display: swap (или system font stack — лучший вариант для in-app)

Мобильное (75% заказов)

  • Sticky bottom bar: Telegram / Позвонить / Рассчитать — 3 кнопки по 48px
  • Tap targets ≥ 44×44px — Apple HIG и WCAG 2.2 §2.5.5
  • Body font ≥ 16px — иначе Safari увеличивает сам
  • safe-area-inset-bottom для iPhone X+ — кнопки не перекрыты жестом
  • viewport-fit=cover в meta viewport

In-app совместимость (Telegram, iMessage, WhatsApp)

  • System font stack — НЕ Google Fonts (могут не загрузиться в in-app)
  • Все CSS inline в <head> — не блокируются
  • Все JS inline или минимальные — с defer
  • Нет backdrop-filter — только solid backgrounds
  • Нет position: sticky без fallback (на in-app может не работать)
  • SVG inline — не external файлы
  • Картинки в JPEG с WebP fallback (не наоборот)

Конверсия

  • Калькулятор «от X ₽/гость» на главной — 3-4 параметра, обновление в реальном времени
  • 3 пакета: Classic / Signature / Premium — с ценой «от» и составом
  • Форма 5 полей: имя, телефон, дата, гости, тип — бюджет опционально
  • Telegram-кнопка рядом с формой — +18% мобильных заявок
  • Trust-сигналы: 25+ элементов на разных страницах (отзывы, логотипы, цифры, сертификаты)
  • HTML-меню, не PDF — с фильтрами по диетам и ценам
  • 3 канала связи: WhatsApp + Telegram + телефон в шапке

SEO и аналитика

  • 10 обязательных страниц: Home, Services, Menu, Cases, About, FAQ, Contacts, B2B, Weddings, Tasting
  • JSON-LD schema: FoodEstablishment + Restaurant + hasMenu на каждой странице
  • Яндекс.Метрика + Яндекс.Вебмастер (не Google)
  • XML sitemap.xml + robots.txt
  • Яндекс.Карты + 2ГИС виджеты с реальными отзывами
  • Ежемесячный контент-апдейт: 1 кейс + 1 пост в блог + обновление сезонного меню
