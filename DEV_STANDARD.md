### Статусы проверок

| Статус | Значение | Действие |
|--------|---------|----------|
| ✅ PASS | Проверка пройдена | Продолжить |
| ❌ FAIL (critical) | Критическая ошибка | БЛОКИРУЕТ commit/deploy |
| ❌ FAIL (non-critical) | Некритическая проблема | Предупреждение, commit разрешён |
| ⏭️ SKIP | Невозможно автоматизировать | Честно отмечено, предложена альтернатива |
| 🔧 NEEDS VERIFY | Требуется ручная проверка | Не считать пройденным |

### Что НЕ автоматизировано (честно)

| Проверка | Статус | Альтернатива |
|----------|--------|-------------|
| Пиксельное сравнение скриншотов | ⏭️ SKIP | Размер файла как proxy. Установить Percy/Chromatic для продакшена |
| Lighthouse CI | ⏭️ SKIP | Navigation Timing API как proxy. Настроить Lighthouse CI отдельно |
| Core Web Vitals (LCP, CLS, FID) | ⏭️ SKIP | Async observer не работает синхронно. Использовать web-vitals в продакшене |
| Цветовой контраст (WCAG) | ⏭️ SKIP | Дизайн-система #1A1714 на #FAFAF7 = >12:1 (AAA). Установить axe-core/pa11y |
| Функциональные тесты форм | ЧАСТИЧНО | agent-browser fill + submit. Нужен Playwright Test для полного покрытия |
| E2E тесты пользовательских путей | ЧАСТИЧНО | agent-browser клики по ключевым путям. Нужен Playwright Test |

## 3. PRE-COMMIT HOOK

**Автоматически запускается перед каждым `git commit`.**

### Быстрый режим (по умолчанию)
Запускает ТОЛЬКО статические проверки (P1-P3, P8) — занимает ~30 сек:
- Build check
- ignoreBuildErrors check
- TypeScript check
- ESLint check
- Broken image references
- Bug registry info

### Полный режим
```bash
QUALITY_PIPELINE_QUICK=false git commit -m "message"
```
Запускает ВСЕ 30 проверок включая браузерное тестирование — занимает ~2-3 мин.

### Обход (ТОЛЬКО для process-документов)
```bash
git commit --no-verify -m "docs: update process documentation"
```
⚠️ Использовать ТОЛЬКО для изменений в .md файлах, НЕ затрагивающих код сайта.

## 4. РАБОЧИЙ ЦИКЛ — 6 ФАЗ

### ФАЗА 1: АНАЛИЗ (не трогать код!)

**Цель:** Понять ЧТО менять и ЧТО МОЖЕТ сломаться.

1. Сформулировать задачу одним предложением
2. Перечислить конкретные файлы, которые будут затронуты
3. Перечислить компоненты, которые МОГУТ пострадать
4. Проверить BUG_REGISTRY.md — есть ли открытые баги в этих файлах?
5. Оценить риски: z-index конфликты, pointer-events, mobile breakpoints
6. Записать план в WORKLOG

### ФАЗА 2: ИЗМЕНЕНИЕ (минимальное)

**Цель:** Изменить ТОЛЬКО то, что запланировано.

1. Не добавлять "пока здесь" улучшения
2. Не рефакторить смежный код "заодно"
3. Максимум 5 файлов за итерацию
4. Каждый изменённый файл — осознанный выбор

### ФАЗА 3: СТАТИЧЕСКАЯ ПРОВЕРКА

**Цель:** Код компилируется без ошибок.

1. `npm run build` — без ошибок
2. `npx tsc --noEmit` — 0 ошибок
3. Нет сломанных медиа-ссылок
4. ESLint — 0 критических ошибок

### ФАЗА 4: РЕАЛЬНАЯ ПРОВЕРКА (agent-browser)

**Цель:** Сайт РЕАЛЬНО работает в браузере.

1. Console errors = 0
2. Кликнуть на КАЖДЫЙ интерактивный элемент
3. Проверить mobile viewport (375x812)
4. Проверить что старый функционал работает
5. Скриншоты как доказательство
6. Каждый клик проверен: нет "covered by" ошибок

### ФАЗА 5: ПОИСК ОШИБОК (3 внутренних критика)

**Критик #1 — "Что сломалось?"** — z-index, pointer-events, перекрытия  
**Критик #2 — "Что вернулось?"** — BUG_REGISTRY, известные проблемные места  
**Критик #3 — "Мобильная версия?"** — кликабельность, читаемость, touch targets

### ФАЗА 6: РЕШЕНИЕ

- Найдены ошибки → ФАЗА 2 → повторить ФАЗЫ 3-5
- 2 полных цикла без новых ошибок → можно commit
- НИКОГДА не commit после первого прохода

## 5. ПРАВИЛА ДЛЯ "ИСПРАВЛЕНО"

| Запрещено | Разрешено |
|-----------|-----------|
| "✅ исправлено" | "🔧 BUG-001: agent-browser click @e93 → Done (было: covered by)" |
| "✅ кнопка работает" | "🔧 agent-browser click @e46 → ✓ Done, no 'covered by' error" |
| "✅ добавлена ссылка" | "🔧 agent-browser snapshot → link found [ref=e36]" |

Статусы подтверждения:
- **✔ VERIFIED** — есть объективное подтверждение (скриншот/лог/команда)
- **✅ FIXED** — код изменён, но не проверен в браузере
- **❌ UNVERIFIED** — "исправлено" без доказательства = НЕ исправлено
