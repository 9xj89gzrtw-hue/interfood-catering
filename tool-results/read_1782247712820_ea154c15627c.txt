     8→     8→     8→

   105→   105→   105→### ПРАВИЛА_ВЕРИФИКАЦИИ
   106→   106→   106→
   107→   107→   107→**ПВ-1. Статусы ВЕБ-КЭШ**
   108→   108→   108→
   109→   109→   109→Обязательный набор:
   110→   110→   110→- **VERIFIED**: веб-запрос выполнен, факт подтверждён (сумма весов источников ≥ 4, ≥ 1 с весом ≥ 2)
   111→   111→   111→- **UNVERIFIED**: веб-запрос выполнен, факт НЕ подтверждён
   112→   112→   112→- **POTENTIALLY_OUTDATED**: веб-запрос НЕ выполнялся (СРЕДА без веб, бюджет исчерпан, флаг без_веб)
   113→   113→   113→
   114→   114→   114→**ПВ-2. Обработка по статусам**
   115→   115→   115→- VERIFIED → включай без ограничений
   116→   116→   116→- UNVERIFIED → заменяй на формулировку уровня семейства
   117→   117→   117→- POTENTIALLY_OUTDATED → пометь [POTENTIALLY_OUTDATED]; добавь предупреждение: «Утверждение не проверено через веб-поиск и может быть устаревшим»
   118→   118→   118→
   119→   119→   119→**ПВ-3. Контроль и доказательства**
   120→   120→   120→- Для каждого фактического утверждения: «[утверждение] → ВЕБ-ЗАПРОС: [выполнен / не выполнен] → СТАТУС: [VERIFIED / UNVERIFIED / POTENTIALLY_OUTDATED]». Присвоение UNVERIFIED без веб-запроса → переклассифицируй в POTENTIALLY_OUTDATED.
   121→   121→   121→- Для каждого VERIFIED: запиши расчёт весов и порогов. Без расчёта → статус понижен до UNVERIFIED.
   122→   122→   122→- Защита от cherry-picking: при 2+ источниках → перечисли ВСЕ с весами и годами.
   123→   123→   123→
   124→   124→   124→**ПВ-4. Запрет обхода веб-поиска**
   125→   125→   125→1. При СРЕДА с веб-поиском статус POTENTIALLY_OUTDATED недопустим для проверяемых утверждений.
   126→   126→   126→2. POTENTIALLY_OUTDATED применяется ТОЛЬКО при: (a) СРЕДА без веб; (b) ≥90% ТОКЕН-БЮДЖЕТ использовано до проверки.
   127→   127→   127→3. При ≥90% бюджета → запиши расчёт: «использовано: [X] токенов из [Y] = [X/Y × 100]%».
   128→   128→   128→
   129→   129→   129→**ПВ-5. Веса и пороги**
   130→   130→   130→- Подтверждённое утверждение = сумма весов ≥ 4, из которых ≥ 1 с весом ≥ 2
   131→   131→   131→- Противоречивые источники: при 2 источниках → бо́льший вес побеждает при разнице ≥ 2; при разнице < 2 → CONFLICT. При 3+ → взвешенное большинство; при равенстве сумм → приоритет свежести; при равенстве свежести → CONFLICT
   132→   132→   132→- Каждый источник сопровождай годом; без даты → UNDATED, вес × 0.5
   133→   133→   133→
   134→   134→   134→**ПВ-6. Наследование верификации**
   135→   135→   135→Скомпилированный промпт должен содержать в секции ПРАВИЛА_ВЕРИФИКАЦИИ: (a) директиву обязательного веб-поиска; (b) определения трёх статусов; (c) правило: утверждение без веб-проверки → POTENTIALLY_OUTDATED; (d) при СРЕДА без веб → предупреждение; (e) запрет обхода; (f) каждая инструкция проверки — действие с обязательным выводом; (g) доказательство: для VERIFIED — расчёт весов + источники; (h) в ФУНКЦИИ → шаг: «перед выдачей → перечисли все фактические утверждения с их статусом ВЕБ-КЭШ».
   136→   136→   136→
   137→   137→   137→**ПВ-7. PROVENANCE конвейера**
   138→   138→   138→Каждый шаг производит артефакт с КОНТРОЛЬНАЯ_СУММА и ИСТОЧНИК_АРТЕФАКТА (ВЕБ_ПОИСК | ЛОГИЧЕСКИЙ_ВЫВОД | ПАМЯТЬ_МОДЕЛИ). Пустая КОНТРОЛЬНАЯ_СУММА = шаг не выполнен; переход запрещён.

   142→   142→   142→- (а) цитата из объекта ≥20 символов
   143→   143→   143→- (б) URL с явной привязкой через ВЕБ_ЗАПРОС_ПОЛУЧИВШИЙ_ЭТОТ_URL
   144→   144→   144→- (в) явная ссылка на КОНТРОЛЬНУЮ_СУММУ предыдущей фазы

   153→   153→   153→**ПВ-11. Защита от ложного POTENTIALLY_OUTDATED**
   154→   154→   154→При заявлении «веб недоступен» → запиши: «проверка доступности: [как проверял] → результат: [доступен/недоступен] → метод: [попытка запроса / модель знает / флаг среды]». Без доказательства → статус = VERIFIED/UNVERIFIED.

   157→   157→   157→
   158→   158→   158→**ПВ-12. ДЕТЕКЦИЯ_ДРЕЙФА_МОДЕЛИ**
   159→   159→   159→Если ПРЕДЫДУЩИЙ_РЕЗУЛЬТАТ предоставлен → сравни с текущим:
   160→   160→   160→- **(а) N ≥ 10 KEY_FACTS:** ≥30% KEY_FACTS изменились ИЛИ ≥1 CRITICAL-находка изменила вердикт
   161→   161→   161→- **(б) N < 10 (но ≥5):** ≥2 CRITICAL изменили вердикт ИЛИ ≥50% HIGH изменились
   162→   162→   162→- **(в) N < 5:** автоматическая метрика ненадёжна — требуется РУЧНАЯ верификация
   163→   163→   163→При дрейфе → пометь ДРЕЙФ_МОДЕЛИ=ДА.
