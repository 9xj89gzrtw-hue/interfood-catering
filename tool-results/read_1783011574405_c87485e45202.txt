    12→## 1.1 Scroll-Driven Animations API — Advanced Patterns
    13→
    14→### Description
    15→Tie any CSS `@keyframes` animation directly to scroll position with zero JavaScript. No `IntersectionObserver`, no scroll-event listeners, no `requestAnimationFrame`. The browser handles everything on the compositor thread for jank-free 60fps.
    16→
    17→### Browser Support (2026)
    18→- Chrome 115+ ✅ | Edge 115+ ✅ | Safari 18+ ✅ | Firefox 132+ ✅
    19→- **Baseline Newly Available** as of early 2026 (Interop 2026 focus)
    20→
    21→### Code Snippet — Parallax Menu Cards on Scroll
    22→
    23→```css
    24→/* globals.css — Scroll-driven parallax for menu cards */
    25→@keyframes reveal-up {
    26→  from {
    27→    opacity: 0;
    28→    transform: translateY(60px) scale(0.95);
    29→  }
    30→  to {
    31→    opacity: 1;
    32→    transform: translateY(0) scale(1);
    33→  }
    34→}
    35→
    36→.menu-card {
    37→  animation: reveal-up linear both;
    38→  animation-timeline: view();
    39→  animation-range: entry 0% entry 60%;
    40→}
    41→
    42→/* Advanced: Horizontal scroll-driven progress bar */
    43→@keyframes progress {
    44→  from { width: 0%; }
    45→  to { width: 100%; }
    46→}
    47→
    48→.scroll-progress {
    49→  animation: progress linear;
    50→  animation-timeline: scroll(root);
    51→}
    52→
    53→/* Advanced: Image reveal on scroll using view() timeline */
    54→@keyframes zoom-reveal {
    55→  from {
    56→    clip-path: inset(45% 45% 45% 45% round 50%);
    57→    opacity: 0.3;
    58→  }
    59→  to {
    60→    clip-path: inset(0% 0% 0% 0% round 0%);
    61→    opacity: 1;
    62→  }
    63→}
    64→
    65→.hero-image {
    66→  animation: zoom-reveal linear both;
    67→  animation-timeline: view();
    68→  animation-range: entry 0% cover 40%;
    69→}
    70→```

   129→## 1.2 View Transitions API — Per-Element & Cross-Document
   130→
   131→### Description
   132→Create smooth, native-feeling page transitions without Framer Motion. Per-element transitions let specific elements morph between pages (e.g., a menu card thumbnail expanding into a full detail page). Cross-document transitions work across full-page navigations (MPA mode) — critical for SEO-friendly Next.js pages.
   133→
   134→### Browser Support (2026)
   135→- Same-document: Chrome 111+ ✅ | Safari 18+ ✅ | Firefox 132+ ✅
   136→- Cross-document (MPA): Chrome 126+ ✅ | Safari 18+ ✅ | Firefox: Partial (expected full 2026)
   137→- **Per-element `view-transition-name`**: All major browsers ✅
   138→

   260→## 1.3 CSS @starting-style — Entry Animations

   265→### Browser Support (2026)
   266→- Chrome 117+ ✅ | Safari 17.4+ ✅ | Firefox 128+ ✅

   555→## 2.1 Speculation Rules API — Prefetch/Prerender on Hover
   556→
   557→### Description
   558→Instruct the browser to prefetch or prerender likely next navigations. When a user hovers over a menu link, the destination page can be fully prerendered in the background — making the navigation instant.
   559→
   560→### Browser Support (2026)
   561→- Chrome 121+ ✅ (prefetch) | Chrome 122+ ✅ (prerender) | Edge ✅
   562→- Safari: Not yet | Firefox: Not yet
   563→- Used on ~12% of page loads as of late 2025
   564→
   565→### Code Snippet
   566→
   567→```html
   568→<!-- Inline speculation rules in layout.tsx -->
   569→<script type="speculationrules">
   570→{
   571→  "prerender": [
   572→    {
   573→      "where": {
   574→        "href_matches": "/menu/*",
   575→        "relative_to": "document"
   576→      },
   577→      "eagerness": "moderate"
   578→    }
   579→  ],
   580→  "prefetch": [
   581→    {
   582→      "where": {
   583→        "and": [
   584→          { "href_matches": "/*" },
   585→          { "not": { "href_matches": "/admin/*" } }
   586→        ]
   587→      },
   588→      "eagerness": "conservative"
   589→    }
   590→  ]
   591→}
   592→</script>
   593→```
   594→
   595→### Next.js Implementation
   596→
   597→```tsx
   598→// components/SpeculationRules.tsx
   599→export default function SpeculationRules() {
   600→  const rules = {
   601→    prerender: [
   602→      {
   603→        where: { href_matches: "/menu/*" },
   604→        eagerness: "moderate"
   605→      }
   606→    ],
   607→    prefetch: [
   608→      {
   609→        where: {
   610→          and: [
   611→            { href_matches: "/*" },
   612→            { not: { href_matches: "/admin/*" } },
   613→            { not: { href_matches: "/api/*" } }
   614→          ]
   615→        },
   616→        eagerness: "conservative"
   617→      }
   618→    ]
   619→  };
   620→
   621→  return (
   622→    <script
   623→      type="speculationrules"
   624→      dangerouslySetInnerHTML={{ __html: JSON.stringify(rules) }}
   625→    />
   626→  );
   627→}
   628→```
   629→

   693→## 2.3 Early Hints (103 Status)
   694→
   695→### Description
   696→The server sends `103 Early Hints` with `Link` headers before the full response is ready. The browser starts preloading critical resources while the server is still processing. Especially powerful with Cloudflare or Vercel Edge.
   697→
   698→### Browser Support (2026)
   699→- Chrome 103+ ✅ | Firefox 109+ ✅ | Safari 18+ ✅ | Edge ✅
   700→
   701→### Code Snippet — Next.js Middleware with Early Hints
   702→
   703→```tsx
   704→// middleware.ts
   705→import { NextResponse } from "next/server";
   706→import type { NextRequest } from "next/server";
   707→
   708→export function middleware(request: NextRequest) {
   709→  const response = NextResponse.next();
   710→
   711→  response.headers.set(
   712→    "Link",

   991→## 3.6 Pull-to-Refresh Custom Implementation
   992→
   993→### Description
   994→Replace browser default pull-to-refresh with a custom branded animation using `overscroll-behavior-y: contain`.
   995→
   996→### Browser Support (2026)
   997→- `overscroll-behavior`: All major ✅
   998→
   999→### Code Snippet
  1000→
  1001→```tsx
  1002→// components/PullToRefresh.tsx
  1003→"use client";
  1004→
  1005→import { useState, useRef, useCallback } from "react";
  1006→import "./PullToRefresh.css";
  1007→
  1008→export default function PullToRefresh({ children, onRefresh }) {
  1009→  const [pullDistance, setPullDistance] = useState(0);
  1010→  const [isRefreshing, setIsRefreshing] = useState(false);
  1011→  const startY = useRef(0);
  1012→  const containerRef = useRef<HTMLDivElement>(null);
  1013→
  1014→  const handleTouchStart = useCallback((e: React.TouchEvent) => {
  1015→    if (containerRef.current?.scrollTop === 0) {
  1016→      startY.current = e.touches[0].clientY;
  1017→    }
  1018→  }, []);
  1019→
  1020→  const handleTouchMove = useCallback((e: React.TouchEvent) => {
  1021→    if (containerRef.current?.scrollTop !== 0) return;
  1022→    const diff = e.touches[0].clientY - startY.current;
  1023→    if (diff > 0) {
  1024→      setPullDistance(Math.min(diff * 0.5, 80));
  1025→    }
  1026→  }, []);
  1027→
  1028→  const handleTouchEnd = useCallback(async () => {
  1029→    if (pullDistance > 60) {
  1030→      setIsRefreshing(true);
  1031→      await onRefresh();
  1032→      setIsRefreshing(false);
  1033→    }
  1034→    setPullDistance(0);
  1035→  }, [pullDistance, onRefresh]);
  1036→
  1037→  return (
  1038→    <div
  1039→      ref={containerRef}
  1040→      className="pull-refresh-container"
  1041→      onTouchStart={handleTouchStart}
  1042→      onTouchMove={handleTouchMove}
  1043→      onTouchEnd={handleTouchEnd}
  1044→    >
  1045→      <div
  1046→        className="pull-indicator"
  1047→        style={{
  1048→          transform: `translateY(${pullDistance - 40}px)`,
  1049→          opacity: pullDistance / 60,
  1050→        }}
  1051→      >
  1052→        {isRefreshing ? "Refreshing menu..." : "Pull for fresh menu"}
  1053→      </div>
  1054→      {children}
  1055→    </div>
  1056→  );
  1057→}
  1058→```

  1390→    if (navigator.share) {
  1391→      try {
  1392→        await navigator.share(shareData);
  1393→        setShared(true);

  1395→        await navigator.clipboard.writeText(url);
  1396→        setShared(true);
  1397→      }
  1398→    } else {
  1399→      await navigator.clipboard.writeText(url);
  1400→      setShared(true);
  1401→    }
  1402→  };
  1403→
  1404→  return (
  1405→    <button onClick={handleShare}>
  1406→      {shared ? "Shared!" : "Share"}
  1407→    </button>
  1408→  );

  1622→## 6.3 CSS Houdini Paint Worklets
  1623→
  1624→### Description
  1625→Custom CSS rendering on the compositor thread. Build generative patterns, noise textures, and animated backgrounds directly in CSS.
  1626→
  1627→### Browser Support (2026)
  1628→- Chrome/Edge ✅ | Safari: Partial | Firefox: Not yet
  1629→- Use `css-paint-polyfill` for cross-browser support
  1630→
  1631→### Code Snippet
  1632→
  1633→```js
  1634→// public/worklets/noise-worklet.js
  1635→class NoisePainter {
  1636→  static get inputProperties() {
  1637→    return ["--noise-scale", "--noise-opacity", "--noise-color"];
  1638→  }
  1639→
  1640→  paint(ctx, size, props) {
  1641→    const scale = parseFloat(props.get("--noise-scale").toString()) || 1;
  1642→    const opacity = parseFloat(props.get("--noise-opacity").toString()) || 0.05;
  1643→
  1644→    const imageData = ctx.createImageData(size.width, size.height);
  1645→    const data = imageData.data;
  1646→
  1647→    for (let i = 0; i < data.length; i += 4) {
  1648→      const noise = Math.random() * 255 * scale;
  1649→      data[i] = noise;
  1650→      data[i + 1] = noise;
  1651→      data[i + 2] = noise;
  1652→      data[i + 3] = opacity * 255;
  1653→    }
  1654→
  1655→    ctx.putImageData(imageData, 0, 0);
  1656→  }
  1657→}
  1658→
  1659→registerPaint("noise", NoisePainter);
  1660→```
